# Code Wiki — TrainFlow Design Archive

This repository is not an executable application. It is a **design + specification archive** for a mobile-first fitness PWA called **TrainFlow**, containing:

- A master product specification describing the intended architecture and modules: [trainflow_especifica_o_mestre_do_produto_1.md](file:///workspace/stitch_modern_application_suite/trainflow_especifica_o_mestre_do_produto_1.md)
- A design-system reference (tokens + guidelines): [DESIGN.md](file:///workspace/stitch_modern_application_suite/high_performance_athletic/DESIGN.md)
- 42 standalone HTML prototype screens (`**/code.html`) using Tailwind via CDN: [stitch_modern_application_suite](file:///workspace/stitch_modern_application_suite)

This wiki documents:

- What the repository contains today (artifacts, structure)
- The intended system architecture (from the master spec)
- Module responsibilities and dependencies (conceptual, as implementation code is not present)
- Key planned endpoints/functions (as described in the spec)
- How to view the HTML prototypes locally
